# Weather App

This is a simple weather application that displays the weather for a selected city.

## Deployment

To deploy this application to GitHub Pages, follow these steps:

1. Push the `gh-pages` branch to your remote repository.
2. Go to your repository's settings.
3. In the "Pages" section, select the `gh-pages` branch as the source.
4. Save your changes.

Your website should now be available at `https://<your-username>.github.io/<repository-name>`.
